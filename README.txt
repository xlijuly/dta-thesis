This repository contains the data and code for the MA thesis "Large Language Models as Annotators for Affective Dimensions: Evaluating Agreement with and Substitution for Human Annotators Across Annotation Methods" by Xinran Li (2025-2026). 

Content:
tuple_generation: data and code for generating tuples required for LLM annotation using pairwise comparison and best-worst scaling. 
annotation: data and code for performing the annotation experiment with LLMs.
score_conversion: data and code for converting the raw annotations from pairwise comparison and best-worst scaling to real-valued scores for analysis.
analysis: data and code for analyzing and visualizing the results.

Detailed contents can be found in the README files of these directories.

Note: some data used and scripts from previous studies are not shared in this public repository for privacy issues, but they have been submitted along with the thesis.
